<a id="play"></a>

## 🎮 开始游戏

玩游戏不需要 Unity、Git 或本仓库。请从 **[最新发行版](https://github.com/JoppieToppie/Galaxy-on-Fire-2-Unity-Remake/releases/latest)** 下载适合你平台的版本：

| 平台 | 下载 | 安装方法 |
|---|---|---|
| **Windows** 10 / 11（64 位） | `GoF2Remake-Windows-<version>.zip` | 解压后，运行 `GoF2Remake` 文件夹中的 `GoF2Remake.exe` |
| **Linux**（x86_64） | `GoF2Remake-Linux-<version>.zip` | 解压后运行 `GoF2Remake.x86_64`（如果无法启动：`chmod +x GoF2Remake.x86_64`） |
| **Android**（ARM64） | `GoF2Remake-Android-<version>.apk` | 把 APK 复制到手机上并打开；系统询问时，允许安装来自此来源的应用 |
| **Windows（UWP 应用）** | `GoF2Remake-UWP-<version>.zip` | 解压后，右键点击 `Install.ps1` > **使用 PowerShell 运行**（会询问是否信任该包的测试证书） |
| 专用服务器 | `GoF2Remake-WindowsServer-…` / `-LinuxServer-…` | 参见 [SERVER.md](../../SERVER.md)；另有 Docker 镜像 `ghcr.io/joppietoppie/gof2-server` |

- **版本号：** 每个版本的版本号就是它发布的日期和时间（例如 `2026.11.02.0622`），各平台相同，显示在主菜单中。多人游戏只能在版本相同的玩家之间进行。
- **更新：** 有新版本发布时，主菜单会显示**有可用更新**。从 2026.11.02 之后的版本开始，这个按钮会就地更新游戏，并且只下载变化的部分（Windows、Linux 和 Android；UWP 应用通过 Windows 的 App Installer 更新）。2026.11.02 及更早的版本需要最后再完整下载一次。
- **存档**与游戏文件分开保存，所以更新或重新安装都不会丢失存档。在**读取游戏**中可以把所有存档导出、导入为一个文件，方便转移到另一台电脑或手机上。
- **UWP 版本**不支持 Discord 状态、手柄陀螺仪、存档文件对话框、VR 和专用服务器。

> [!TIP]
> 全新安装后的玩法和**原版游戏**一致。选项 > 游戏玩法 > **游戏体验**可以一次性开启重制版的各项新增内容：*原版*、*外观增强*（机库飞行和动画对话）或*重制版*（全部新增内容）。每个选项也可以单独更改。

### Linux 和 Steam Deck

- **手柄：** Xbox、PlayStation 和 Switch Pro 手柄可直接使用。在 Steam Deck 的桌面模式下，或者使用游戏无法识别的手柄时，请把游戏添加到 Steam（*添加非 Steam 游戏*），并从 Steam 启动：Steam 输入会把它识别为 Xbox 手柄。
- **在 Steam Deck 上通过 Steam 启动：** Steam 会设置 `SteamDeck=1`，这会导致 Unity 的 Linux 播放器卡在约 0 FPS（[#232](https://github.com/JoppieToppie/Galaxy-on-Fire-2-Unity-Remake/issues/232)）。游戏会在去掉该变量后自动重启一次（窗口可能会打开两次）。如果仍然卡住，请把快捷方式的启动选项设为 `env -u SteamDeck %command%`。

<a id="features"></a>

## ✨ 功能

- **剧情：** 完整的主线战役，包括序章、Void 和结局，另有 Valkyrie 和 Supernova 两个资料片。配音对话（英语或德语）、角色肖像、无线电对话和过场动画。
- **飞行：** 原版的飞行模型和追尾镜头、驾驶舱视角，以及可选的 EVERSPACE 2 风格自由飞行模式。空间站轨道与原版完全一致地重建，包括天空、行星、恒星和小行星带。
- **旅行：** 自动驾驶、行星跳跃、快进、星图、星门、Khador 驱动器和 Void 的虫洞。**星门路线规划**会按最快或最安全的路线，一个星门接一个星门地带你飞往任何星系。可选的 **Khador Slipstream** 是星系内和星系间的快速旅行。
- **战斗：** 所有武器（导弹、光束、EMP、水雷、炮塔、哨戒炮、Liberator 等）、NPC 交通与 AI、主力舰、海盗基地、Specter 和通缉犯。隐形装置、紧急系统、时间延长器、修复光束和伽马护盾。**Supernova Challenge** 街机模式带有连击得分和最高分记录。
- **经济与空间站：** 机库、商店和飞船经销商、有酒吧代理人和各种自由任务的太空休息室、蓝图、僚机、勋章以及 Kaamo 俱乐部。
- **采矿：** 带钻探小游戏的小行星采矿、Mido **矿厂**（把矿石加工成核心、太空废物分拣）、气体云、入侵黑客和对接物体。
- **合作战役（实验性）：** 一起游玩剧情，默认 2 到 4 名玩家，在主菜单中有专门的按钮。房主可以继续单人存档，也可以开始新游戏；敌人还可以随玩家人数变强。
- **多人游戏（实验性）：** 共享的宇宙，有小队、派系、竞技场比赛、贸易和事件游戏模式。参见[多人游戏](#multiplayer)。
- **模组：** 新的物品、飞船、星系、空间站、角色、任务乃至完整战役，都可以用游戏内的 **Mod Builder** 制作。参见[模组](#mods)。
- **VR（实验性）：** 通过 OpenXR 支持 PC VR。参见 [VR](#vr)。
- **速通计时器：** 按剧情章节或步骤分段，支持 LiveSplit 分段文件和 LiveSplit 连接。
- **操作与屏幕：** 触屏、体感倾斜、键盘鼠标和手柄（自动选择 Xbox 或 PlayStation 按键图标），全部可自定义按键。在 Windows 上，DualSense、DualShock 4 或 Switch Pro 支持陀螺仪瞄准；手柄和 Android 手机支持震动反馈。支持从 4:3 到 32:9 的横屏。
- **语言：** 原版的各种语言，外加荷兰语、简体中文和印地语翻译，并补全了韩语、日语和阿拉伯语（共 14 种），可选德语或英语配音。

- **四种难度**（容易、普通、困难、极限），游戏中可随时更改。
- **便利功能：** 全部出售 / 全部购买、智能目标锁定和解除锁定的控制、任务窗口的地图可以直接前往任务目标、全图星图总览、以简短提示显示的勋章、完整 / 精简 / 关闭三档飞行 HUD（F1）、带距离的远处飞船标记、冷却图标、FPS 计数器，以及每种武器各自的射击音效。
- **画面：** 低 / 中 / 高预设、远处飞船、空间站和小行星的细节层级、SMAA / FXAA / TAA，以及超分辨率（FSR 1 和 STP 全平台可用，NVIDIA DLSS 和 AMD FSR 2 / 3 / 4 仅限 Windows）。
- **拍照模式**（飞行中的 Action Freeze，机库中的检视飞船）：自由相机、视野、倾斜、景深、快门角度和长曝光、变焦模糊、胶片风格、曝光、色彩、边框，以及最高可达屏幕尺寸 4 倍的截图。

- **调试工具**（选项 > 游戏玩法）：跳到任意剧情步骤、作弊、给予物品、生成飞船和物体、驾驶任意船体、保存和读取飞船配置。当前的剧情步骤和空间站可以显示在右下角，这样 bug 截图就能说明问题发生在哪里。
- Windows 上的 **Discord Rich Presence**。

## 🌐 多人游戏

多人游戏仍处于实验阶段。同一场游戏中的所有人共享一个通关后世界的宇宙：你们能在太空和机库里互相看到，组成小队、一起做酒吧任务、共享商店和 NPC 交通，建立拥有空间站的派系，交易信用点和货物，并在竞技场比赛中战斗（房主选择 PvP 时则可以在任何地方开战）。可以通过服务器浏览器（显示每个游戏的区域和延迟）、加入码或局域网加入。

新飞行员从停靠在 Dis 的 Betty 开始，带着 10 000 信用点。专用服务器（或房主的持久世界）会保存每位玩家的进度；你的单人存档绝不会被动到。只有**完全相同的游戏版本**才能一起玩。

## 🧩 模组

模组以数据形式添加或修改游戏内容，无需代码也无需 Unity：物品（带有自己的武器特效和音效）、来自 GLB 模型的飞船、皮肤、星系和空间站（带有自己的模型、行星、恒星、天空、机库和酒吧）、带肖像和配音的角色、音乐和音效、蓝图、任务和酒吧任务，以及出现在新游戏下的完整战役。

**安装模组：** 在主菜单的**模组**界面中，点击**导入模组**并选择模组的 `.zip`（Android 上也一样）。或者自己把模组（文件夹或它的 `.zip`）放进 Mods 文件夹，然后在模组界面中启用它。界面上的**打开模组文件夹**按钮可以打开该文件夹：

| 平台 | Mods 文件夹 |
|---|---|
| Windows | `%USERPROFILE%\AppData\LocalLow\JoppieToppie\Galaxy on Fire 2\Mods`，或 `GoF2Remake.exe` 旁边的 `Mods` 文件夹 |
| Linux | `~/.config/unity3d/JoppieToppie/Galaxy on Fire 2/Mods`，或游戏旁边的 `Mods` 文件夹 |
| Android | `Android/data/com.joppietoppie.gof2remake/files/Mods`（可通过 USB 访问） |

使用了模组的存档会记住这些模组；不带模组读取它时，会移除其中的模组物品（并退款）。在多人游戏中，由房主决定是否允许模组，加入的玩家需要安装相同的模组。

**制作模组：**

- **[Mod Builder](../notes/mod-builder.md)**（模组 > Mod Builder，实验性）：在游戏内制作飞船、物品、皮肤、角色、任务（用节点图）、星系、空间站、机库和酒吧、武器特效、音频、蓝图、战役和飞船套件，支持撤销、试飞和试玩，并导出完成的模组。它还能缩小模组的模型和贴图，并导入用原版模型制作的社区模组（`.aem` / `.aei`）。你自己的 AI 助手可以通过它的本地 MCP 服务器在其中工作，权限由你决定。
- **手动制作：** 参见模组制作指南 [Modding/README.md](../../Modding/README.md)，示例模组在 [Modding/Examples](../../Modding/Examples)。
- **借助 AI 助手：** [Modding/ai](../../Modding/ai) 中有适用于 Claude、ChatGPT 等的指南。

### VR（实验性）

连接 PC VR 头显并启用 OpenXR 运行时（SteamVR、Meta Quest Link、Windows Mixed Reality）后，用 `-vr` 参数启动 Windows 版（例如创建一个指向 `GoF2Remake.exe -vr` 的快捷方式）。没有头显时，游戏会正常启动。

<details>
<summary>VR 是什么样子</summary>

- **飞行：** 你坐在驾驶舱里。护盾、船体和货舱显示在驾驶舱的屏幕上，雷达位于仪表盘中央，其余 HUD 显示在舱盖上。过场动画会保持地平线水平，并在镜头之间淡入淡出。
- **空间站：** 你站在机库里你的飞船旁边（用握持键抓住它并拉动即可旋转），也可以在酒吧里（指向一位访客并扣动扳机即可交谈）。
- **菜单**显示在一块悬浮的屏幕上；用右手柄指向它并扣动扳机。
- **操作：** 手柄像游戏手柄一样工作（摇杆、扳机、A / B / X / Y，握持键对应 LB / RB）。启用选项 > 控制 >“VR flight: grab the stick and throttle”后，你就改用驾驶舱的侧杆和油门杆飞行。

目前所有飞船的驾驶舱都是一样的。

</details>

## 🛠️ 参与项目

这一部分面向想修改游戏本身（代码、场景和素材）或构建自己的版本的人。**如果只是想玩，请用[发行版](#play)；想添加内容，通常用[模组](#mods)就够了。**

### 环境要求

- **Unity 7000.0.0a12**（一个 alpha 版本，通过 Unity Hub 安装）。为你要构建的平台添加构建支持模块：*Windows Build Support (IL2CPP)*、*Linux Build Support (IL2CPP)*、*Android Build Support*，构建服务器还需要 *Dedicated Server* 模块。
- **Git** 和 **[Git LFS](https://git-lfs.com)**。模型、贴图和音效在 LFS 中约有 2.1 GB，从项目自己的 LFS 服务器获取（在 [.lfsconfig](../../.lfsconfig) 中设置）。
- 构建 **Windows 版**需要：Visual Studio 2022 或更新版本，带有 *Desktop development with C++* 工作负载，以及 Windows 10 / 11 SDK（IL2CPP）。构建 UWP 版还需要 *C++ Universal Windows Platform tools*。

### 把项目跑起来

```bash
git lfs install
```

```bash
git clone https://github.com/JoppieToppie/Galaxy-on-Fire-2-Unity-Remake.git
```

1. 在 Unity Hub 中用 Unity 7000.0.0a12 打开克隆下来的文件夹（*Add > Add project from disk*）。第一次导入需要一段时间。
2. 打开 `Assets/Scenes/Splash.unity`（想跳过开场 Logo 就打开 `MainMenu.unity`），然后点击 **Play**。

场景有 `Splash`（构建索引 0）、`MainMenu`、`Space`（飞行关卡）和 `Station`（停靠状态）。生成的素材（预制体、材质、图标、HUD 图片）已经在仓库中；编辑器中的 **GoF2** 菜单可以重新生成它们，**GoF2 > Tools Overview** 列出了所有工具。

> [!IMPORTANT]
> 不要为这些场景生成光照。它们特意没有烘焙光照：游戏在运行时构建关卡，每个星系都有自己的天空（`SkyReflection` 会据此更新环境光）。烘焙的探针对所有星系来说只会是同一片固定的天空。

### 构建

- 构建其他平台之前，务必先**切换当前的构建配置**（File > Build Profiles > Switch Profile）。URP 只保留当前平台的着色器变体：在 Windows 为当前平台时构建的 Android 版会渲染成一片黑，所以编辑器脚本 `BuildTargetGuard` 会拒绝这样的构建。
- `BuildVersionStamp` 根据 git 提交的日期和时间给每个构建设定版本号。发布时，请设置编辑器进程的 `GOF2_BUILD_VERSION` 环境变量，让所有平台使用同一个版本号。
- 专用服务器：**GoF2 > Build > Linux Dedicated Server** / **Windows Dedicated Server**。`docker/` 文件夹中是服务器镜像。
- 游戏内更新器使用的更新补丁：构建完成后用 **GoF2 > Build > Update Patch**。
