# Galaxy on Fire 2 Remake: mission steps (.gof2mission)

Generated by GoF2 > Build > Modding AI Reference from the game's own step table (the same the game compiles and the
Mod Builder's graph edits). The machine-readable form is `mission.schema.json` beside this file. A mission is
`events/<name>.gof2mission`: `{ "format": "gof2mission", "title", "kind", ..., "steps": [ { "type": ..., fields } ] }`.
Every step that acts on players also takes `who` (wirable): @a everyone the mission is for (default), @trigger the player an "on" block is about, @alive, @docked, @survivors, @r, or @alive[orbit=<station>]. Blocks hold their own
step lists. A field marked (wirable) can hold `{ "$value": "v1" }` instead, wired to a value node in `values`.

## Story

### `dialog`: Conversation

Pages with portraits, like the story's

- `pages`: the pages in order: [{ speaker, text, voice }].

### `radio`: Radio call

A call in the flight HUD

- `speaker`: who calls; Keith, a story character, "mod_id:character", "vossk K'ekki", player.
- `text`: the line.
- `voice`: a voice clip (voices.md or the mod's voices/).

### `objective`: Objective

The Missions window's line and the target on the map

- `text`: the Missions window's line.
- `station`: the gold target on the map (optional).

### `title`: Title

Big text on the screen

- `title`: Title.
- `subtitle`: Line under it.
- `seconds` (wirable): Shown for (seconds; empty: 4); a number, or an expression as a string.

### `note`: Note

A comment for yourself: does nothing

- `text`: Note.

## Flow

### `wait`: Wait

Seconds

- `seconds` (wirable): Seconds; a number, or an expression as a string. Default `3`.

### `waituntil`: Wait until

A condition

- `condition` (wirable): Condition; an expression (guide.md "Conditions"), e.g. kills >= 5.
- `timeout` (wirable): Give up after (seconds); a number, or an expression as a string.

### `if`: If

Steps only when a condition holds, others when it doesn't

- `condition` (wirable): Condition; an expression (guide.md "Conditions"), e.g. kills >= 5.
- `then`: the steps of "Then".
- `else`: the steps of "Else".

### `while`: While

Steps again and again as long as a condition holds

- `condition` (wirable): Condition; an expression (guide.md "Conditions"), e.g. kills >= 5.
- `steps`: the steps of "Do".

### `repeat`: Repeat

Steps a number of times

- `count` (wirable): How many times; an expression. Default `3`.
- `as`: Count in a variable (optional); a variable's name (letters, digits, _).
- `steps`: the steps of "Do".

### `parallel`: At the same time

Steps that run beside the rest of the mission

- `steps`: the steps of "Do".

### `every`: Every few seconds

Steps again and again beside the rest, until the mission ends

- `seconds` (wirable): Every (seconds); a number, or an expression as a string. Default `10`.
- `steps`: the steps of "Do".

### `on`: When something happens

Steps each time the player is destroyed, docks, kills a ship, gets near a point...

- `trigger`: When: died = The player is destroyed, docked = The player docks, launched = The player launches, kill = A spawned ship is destroyed, cleared = Every spawned enemy is gone, entered = The player enters an orbit, near = The player gets near a point, respawned = The player respawns, hacked = The player hacks a wreck, pad = The player docks at a station's pad outside, joined = A player joins, left = A player leaves, pvpkill = A player destroys another. Default `died`.
- `station` (wirable): Only at (optional); the game's number, its name, or a key "mod_id:id".
- `at`: The point (x y z); "x y z" in game units (20 = 1 m). Default `0 0 20000`.
- `radius` (wirable): Within (metres); a number, or an expression as a string. Default `500`.
- `steps`: the steps of "Do".

### `ask`: Ask

A question; each answer runs its own steps

- `speaker`: Asked by; Keith, a story character, "mod_id:character", "vossk K'ekki", player.
- `question`: Question.
- `seconds` (wirable): Time to answer (seconds); a number, or an expression as a string. Default `30`.
- `answers`: each answer runs its own steps.

### `vote`: Vote

Everyone picks an answer; the most picked one runs its steps

- `speaker`: Asked by; Keith, a story character, "mod_id:character", "vossk K'ekki", player.
- `question`: Question.
- `seconds` (wirable): Time to vote (seconds); a number, or an expression as a string. Default `30`.
- `none`: the steps of "Nobody voted".
- `answers`: each answer runs its own steps.

### `random`: Random

One of several branches, by chance

- `branches`: one runs, the bigger its weight the likelier.

### `set`: Set a variable

A number the mission remembers (its variables)

- `variable`: Variable; a variable's name (letters, digits, _).
- `value` (wirable): Value (an expression); an expression. Default `0`.

### `checkpoint`: Checkpoint

A save goes on from here Only on the mission's own line of steps.

- `name`: its name (optional; one word).

### `startquest`: Start a mission

Another mission beside this one

- `quest`: the story mission's name (its file name).

### `startevent`: Next event

Ends this one and starts another event graph or mission

- `event`: Event; an event graph's or quest's name.
- `settings`: Its settings (name=value ..).

### `complete`: Complete

The mission is done, the reward paid

- `reward`: credits (default: the mission's reward).
- `title`: the reward box's title.

### `fail`: Fail

Mission failed

- `title`: what the player is told.

### `stop`: Stop

Ends the mission without a result (an event: its end)


## Places and travel

### `goto`: Go to a station

Waits until the player docks there (or reaches its orbit)

- `station`: the station.
- `dock`: true (default): docked there; false: in its orbit.
- `objective`: the objective meanwhile (optional).

### `system`: Show / hide a system

A system on or off the star map (its routes and jumps too), until reset

- `system`: System; the game's number, its name, or a key "mod_id:id".
- `action`: : show = Show it, hide = Hide it (a player in it is taken out), reset = As the map has it again. Default `show`.

### `waypoint`: Waypoint

A point in an orbit the autopilot flies to

- `station` (wirable): Station; the game's number, its name, or a key "mod_id:id".
- `at`: At (x y z, game units from the station; empty: cleared); "x y z" in game units (20 = 1 m).

### `wormhole`: Wormhole

A wormhole in an orbit; flying in takes the player to its destination

- `station` (wirable): In the orbit of (empty: close it); the game's number, its name, or a key "mod_id:id".
- `at`: At (x y z; empty: 4 km out, beside the launch path); "x y z" in game units (20 = 1 m).
- `to` (wirable): Destination; the game's number, its name, or a key "mod_id:id".
- `void`: Into the Void instead. Default `False`.
- `seconds` (wirable): Open for (seconds; empty: until closed); a number, or an expression as a string.

### `target`: Map target

The gold story icon on the map and the HUD

- `station` (wirable): Station (empty: none); the game's number, its name, or a key "mod_id:id".

### `questorbit`: Quiet orbit

No normal traffic in an orbit (for the mission's own ships)

- `station` (wirable): Station; the game's number, its name, or a key "mod_id:id".
- `on`: Quiet (off: the traffic comes back). Default `True`.

### `restrict`: Restrict travel

No jumps, no docking, both, or only no Khador Drive

- `what`: Refuse: jumps = Jumps, docking = Docking, all = Both, khador = The Khador Drive only, off = Nothing (lift it). Default `jumps`.

### `respawn`: Respawn point

Where a destroyed ship comes back, in space

- `station` (wirable): In the orbit of (empty: none); the game's number, its name, or a key "mod_id:id".
- `at`: At (x y z; empty: in front of the station); "x y z" in game units (20 = 1 m).
- `spread` (wirable): Spread (units); a number, or an expression as a string.
- `delay` (wirable): After (seconds); a number, or an expression as a string.

### `teleport`: Teleport

Moves the player to an orbit or into a hangar

- `station` (wirable): Station; the game's number, its name, or a key "mod_id:id".
- `dock`: Into its hangar. Default `False`.
- `at`: At (x y z; empty: the launch spot); "x y z" in game units (20 = 1 m).

## Ships

### `fight`: Fight

Ships in an orbit; waits until they are destroyed

- `station`: the orbit (empty: wherever the player is).
- `ships`: [{ ship, count (1-10), race, behaviour (enemy / neutral / friendly) }].
- `name`: their name on the lock plate (ship orders use it).
- `quiet`: no other traffic there (default true).
- `objective`: the objective meanwhile (optional).

### `spawn`: Spawn ships

Ships (or an object) beside the player, named for the ship orders

- `ship`: Ship; the game's number, its name, or a key "mod_id:id".
- `count` (wirable): How many (empty: 1); a number, or an expression as a string.
- `race`: Flown by: "" = Its maker, pirate = Pirates, terran = Terran, vossk = Vossk, nivelian = Nivelian, midorian = Midorian, void = Void. Default ``.
- `behaviour`: Toward the player: enemy = Enemy, neutral = Neutral, friendly = Friendly, standing = By the standing. Default `enemy`.
- `name`: Their name (on the lock plate; the orders use it).
- `at`: At (x y z in the orbit; empty: ahead of the player); "x y z" in game units (20 = 1 m).
- `turrets`: Turret items (numbers, a comma between).
- `hull` (wirable): Hull x (empty: as usual; 2 = twice as tough); a number, or an expression as a string.
- `guns` (wirable): Gun damage x (empty: as usual); a number, or an expression as a string.

### `spawntype`: Spawn an NPC ship type

A capital ship, freighter or boss of the NPC ships kind (the pirate boss too), with its own hull, guns and escorts

- `npc`: NPC ship type: battleship, carrier, vossk_battleship, freighter, pirate_boss, or a mod's NPC ship key "mod_id:id". Default `pirate_boss`.
- `name`: Its name (on the lock plate; the orders use it).
- `at`: At (x y z in the orbit; empty: 3.5 km ahead of the player); "x y z" in game units (20 = 1 m).

### `wreck`: Hackable wreck

A damaged freighter the player can dock at and hack ("When something happens": the player hacks a wreck)

- `race`: Freighter: "" = Any, terran = Terran, vossk = Vossk, nivelian = Nivelian, midorian = Midorian. Default ``.
- `name`: Its name (on the HUD; %victim% when hacked).
- `at`: At (x y z in the orbit; empty: 1.5 km ahead of the player); "x y z" in game units (20 = 1 m).

### `shipgoto`: Ship: fly to

A named ship flies somewhere

- `ship`: Ship; the name a spawn / fight step gave the ships.
- `to`: To; a place: player [right up forward] | station [x y z] | x y z | ship <name> [x y z] (game units). Default `station 0 0 20000`.
- `speed` (wirable): Speed (units per ms; a fighter 2); a number, or an expression as a string.
- `radius` (wirable): Arrived within (units); a number, or an expression as a string.
- `fight`: Fights on the way. Default `False`.
- `then`: Then: hold = Hold there, resume = Back to its route, vanish = Vanish, jump = Jump out. Default `hold`.

### `shiproute`: Ship: fly a route

A named ship flies from place to place

- `ship`: Ship; the name a spawn / fight step gave the ships.
- `route`: Places (a / between them). Default `station 0 0 20000 / station 20000 0 20000`.
- `loop`: Round and round. Default `False`.
- `speed` (wirable): Speed (units per ms); a number, or an expression as a string.
- `radius` (wirable): Arrived within (units); a number, or an expression as a string.
- `fight`: Fights on the way. Default `False`.
- `then`: Then: hold = Hold there, resume = Back to its route, vanish = Vanish, jump = Jump out. Default `hold`.

### `shipfollow`: Ship: follow

A named ship flies beside the player or another ship

- `ship`: Ship; the name a spawn / fight step gave the ships.
- `leader`: Follows; a place: player [right up forward] | station [x y z] | x y z | ship <name> [x y z] (game units). Default `player`.
- `offset`: Where beside it (right up forward); "x y z" in game units (20 = 1 m).
- `escort`: Fights what attacks it (escort). Default `True`.
- `speed` (wirable): Speed (units per ms); a number, or an expression as a string.

### `shipattack`: Ship: attack

A named ship attacks the player or another ship, whatever the standing

- `ship`: Ship; the name a spawn / fight step gave the ships.
- `target`: Attacks; a place: player [right up forward] | station [x y z] | x y z | ship <name> [x y z] (game units). Default `player`.

### `shipaction`: Ship: other order

Hold, back to its route, jump out, dock, flee

- `ship`: Ship; the name a spawn / fight step gave the ships.
- `action`: Order: hold = Hold where it is, resume = Back to its route, jump = Jump out, dock = Dock at the station, flee = Flee, then jump out. Default `hold`.
- `seconds` (wirable): Flees for (seconds); a number, or an expression as a string. Default `20`.

### `provoke`: Make hostile

The ships around the player turn on them

- `race`: Only: "" = Every race, pirate = Pirates, terran = Terran, vossk = Vossk, nivelian = Nivelian, midorian = Midorian, void = Void. Default ``.
- `within` (wirable): Within (metres; empty: the whole orbit); a number, or an expression as a string.

## The player

### `reward`: Reward

Credits and items, in the reward box

- `credits`: credits (or an expression).
- `items`: [{ item, amount }].
- `title`: the reward box's title.

### `give`: Give an item

Into the hold, without a box

- `item`: Item; the game's number, its name, or a key "mod_id:id". Default `22`.
- `amount` (wirable): Amount; a number, or an expression as a string. Default `1`.
- `mount`: Mount it (when docked). Default `False`.

### `take`: Take an item

Out of the hold (a hand-in), or off the ship too

- `item`: Item; the game's number, its name, or a key "mod_id:id". Default `22`.
- `amount` (wirable): Amount (empty: all of them); a number, or an expression as a string.
- `mounted`: Mounted ones too (a Khador Drive, a gun..). Default `False`.

### `cargo`: Bring cargo

Waits until the hold has it; handed in, it is taken

- `item`: the item.
- `amount`: how many tonnes.
- `station`: docked there (optional).
- `objective`: the objective meanwhile (optional).
- `take`: handed in: taken from the hold once there.

### `credits`: Credits

Adds (or takes, below 0) credits without a box

- `amount` (wirable): Credits; a number, or an expression as a string. Default `1000`.

### `ship`: Change ship

The player flies another hull (or their own again)

- `own`: Their own ship again. Default `False`.
- `hull`: Ship; the game's number, its name, or a key "mod_id:id".

### `lend`: Lend a ship

The own ship parked, a loaner flown until the mission ends

- `back`: Their own ship back now. Default `False`.
- `hull`: Ship; the game's number, its name, or a key "mod_id:id".
- `keep`: Their equipment and cargo move over. Default `False`.

### `heal`: Repair

Hull, shield and armor full


### `ammo`: Refill ammo

Every secondary to 50


### `kill`: Destroy the ship

The player's ship is destroyed


### `reveal`: Reveal the map

Every system on the star map


### `peace`: Make peace

Every race neutral again


### `standing`: Standing

Moves the standing toward a race (a mod's too), or sets it

- `race`: Toward: terran = Terran, vossk = Vossk, nivelian = Nivelian, midorian = Midorian. Default `terran`.
- `amount` (wirable): Amount (below 0: liked less); a number, or an expression as a string. Default `10`.
- `set`: Set it to the amount. Default `False`.

## Cutscenes

### `cutscene`: Start a cutscene

HUD and controls off, bars

- `letterbox`: Black bars. Default `True`.
- `freeze`: The ship stops. Default `False`.
- `invulnerable`: Invulnerable. Default `True`.

### `camera`: Camera shot

The camera at a place, moving, looking at something

- `from`: From; a place: player [right up forward] | station [x y z] | x y z | ship <name> [x y z] (game units). Default `player 0 600 -2500`.
- `to`: Moves to (optional); a place: player [right up forward] | station [x y z] | x y z | ship <name> [x y z] (game units).
- `seconds` (wirable): Over (seconds); a number, or an expression as a string. Default `3`.
- `look`: Looks at (optional); a place: player [right up forward] | station [x y z] | x y z | ship <name> [x y z] (game units). Default `player`.
- `follow`: Keeps up with what it looks at. Default `False`.
- `fov` (wirable): Field of view (degrees); a number, or an expression as a string.
- `shake` (wirable): Shake (0.1); a number, or an expression as a string.

### `chasecamera`: Chase camera

The normal camera behind the ship again


### `cutsceneend`: End the cutscene

HUD, controls and the chase camera back


### `fade`: Fade

To or from a colour

- `direction`: Fade: out = Out (to the colour), in = In (from it), clear = Clear at once. Default `out`.
- `seconds` (wirable): Seconds; a number, or an expression as a string. Default `1`.
- `colour`: Colour (rrggbb). Default `000000`.

### `letterbox`: Black bars

On or off, without a cutscene

- `on`: On. Default `True`.

## Value nodes (`values`)

- `number` (Number, gives number): `value` value
- `state` (Game state, gives number): `what` what: players / inspace / docked / dead / enemies / ships / time / kills / credits / rank / station / system / ship / campaign / systemsvisited / missionstation / toppoints
- `variable` (Variable, gives number): `name` name
- `math` (Math, gives number): `a` a (number); `b` b (number); `op` operation: + / - / * / / / %
- `compare` (Compare, gives number): `a` a (number); `b` b (number); `op` is: == / != / < / <= / > / >=
- `logic` (And / Or, gives number): `a` a (number); `b` b (number); `op` both / either: and / or
- `not` (Not, gives number): `a` value (number)
- `random` (Random, gives number): `min` from (number); `max` to (number)
- `minmax` (Min / Max, gives number): `a` a (number); `b` b (number); `op` which: min / max
- `floor` (Round down, gives number): `a` value (number)
- `count` (Count players, gives number): `players` players (players)
- `alive` (Ships alive, gives number): `ship` named
- `distance` (Ship's distance, gives number): `ship` named; `at` to x y z
- `cargo` (Cargo of an item, gives number): `item` item
- `docked` (Docked at, gives number): `station` station (orbit)
- `inorbit` (In the orbit of, gives number): `station` station (orbit)
- `visited` (Has visited, gives number): `station` station (orbit)
- `quest` (A quest's state, gives number): `name` quest
- `expression` (Expression, gives number): `text` expression
- `players` (Get players, gives players): `orbit` in the orbit of (optional) (orbit); `who` who: a / alive / space / docked / dead / survivors / r / p
- `orbit` (Get orbit, gives orbit): `station` station

Example: `"values": [ { "id": "v1", "type": "state", "what": "kills" }, { "id": "v2", "type": "compare", "op": ">=", "a": { "$value": "v1" }, "b": 5 } ]`
and an `if` step with `"condition": { "$value": "v2" }` is `if (kills >= 5)`. Writing the expression as text (`"condition": "kills >= 5"`)
works the same; value nodes are what the builder's graph draws.
