# Predictive targeting PIPs

Enable on a scanner with `"stats": { "scanLead": 1 }` (attribute 195). Off by default. The locked, detectable target's measured 3D movement feeds the existing shared acceleration estimator. A PIP is shown for each distinct mounted primary projectile speed/lifetime, using the mean actual muzzle for identical weapons; cyan for projectiles, gold for beams. No target marker is invented when a shot cannot intercept before expiration. Beams use the current aim point within beam reach. No shooter velocity is subtracted because GoF2's projectile simulation does not inherit it. The estimate is advisory, not auto-aim; abrupt maneuvers, spread, geometry and network interpolation may affect hits. Missiles, mines, other secondaries and independent turrets have no PIP. Markers vanish on lost lock, cloak, out-of-range targets, cinematic or turret view. Test with varied primary speeds, stationary/crossing/receding targets, scanner range and multiplayer proxies.
HUD prediction samples only the currently locked target once per rendered frame, separately from the 80 ms NPC/turret motion cache. Remote ships use their interpolated render positions with slightly stronger time-based smoothing; the multiplayer player pose stream remains 20 Hz, so this improves presentation and reaction without adding network traffic. All live, targetable pilot locks (including protected players, squadmates and neutral pilots) work. Cloak and lost scanner contact suppress PIPs. Existing PvP damage restrictions are unchanged. A new lock or discontinuity resets the motion estimate.
